# 🌤 WeatherCal — Погода в Календаре Apple (Челябинск)

Автоматическая интеграция прогноза погоды в **Календарь Apple (iCloud)**. 
Работает локально на Mac и мгновенно синхронизируется с **iPhone, iPad и Apple Watch**.

---

## ✨ Что уже настроено и работает:

- **Город:** Челябинск (настраивается в [config.json](file:///Volumes/Work%20SSD/works/WeatherCal/config.json)).
- **Календарь:** `🌤 Погода` в iCloud.
- **События на 10 дней вперёд:** 
  - Формат в сетке: `🌤 +4° / +11° Преимущественно ясно` (ночь / день, строго на один день).
  - Внутри в заметках: влажность, макс. ветер, вероятность осадков и **почасовой график без лишних нулей** (`00`, `03`, `06`, `09`, `12`, `15`...).
- **Сохранение архива:** прошлые дни **не удаляются** и остаются как ваш персональный дневник погоды за все прошлые месяцы и годы.

---

## 🚀 Ручной запуск

Для обновления прогноза запустите в терминале:

```bash
python3 update_weather.py
```

Скрипт автоматически:
1. Забирает свежие данные с Open-Meteo.
2. Удаляет предварительный прогноз на будущее (сохраняя историю в прошлом).
3. Создает аккуратные карточки на 10 дней вперед с почасовой сводкой.

## ⏰ Как сделать автоматический запуск

### Способ 1. Запуск по расписанию в фоне на Mac (LaunchAgent — Рекомендуется)

Чтобы Mac сам каждое утро (например, в 07:00) обновлял погоду без вашего участия:

Создайте файл `~/Library/LaunchAgents/com.weathercal.sync.plist`:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>Label</key>
    <string>com.weathercal.sync</string>
    <key>ProgramArguments</key>
    <array>
        <string>/usr/bin/python3</string>
        <string>/Volumes/Work SSD/works/WeatherCal/update_weather.py</string>
    </array>
    <key>StartCalendarInterval</key>
    <dict>
        <key>Hour</key>
        <integer>7</integer>
        <key>Minute</key>
        <integer>0</integer>
    </dict>
    <key>RunAtLoad</key>
    <true/>
</dict>
</plist>
```

Активировать автозапуск:
```bash
launchctl load ~/Library/LaunchAgents/com.weathercal.sync.plist
```

---

### Способ 2. Запуск через «Быстрые команды» (в 1 действие)

Если хотите запускать обновление по кнопке или через виджет:
1. В приложении **«Быстрые команды»** создайте команду `Обновить погоду`.
2. Добавьте всего **одно действие**: **`Выполнить скрипт командной строки`** (Run Shell Script):
   ```bash
   /usr/bin/python3 "/Volumes/Work SSD/works/WeatherCal/update_weather.py"
   ```
3. Готово! Никаких сложных циклов и переменных внутри Shortcuts собирать не нужно.

---

### Способ 3. Через Automator / Готовое приложение (.app)

В репозитории уже скомпилировано готовое нативное приложение:
👉 [Обновить погоду.app](file:///Volumes/Work%20SSD/works/WeatherCal/Обновить%20погоду.app)

- **Как запускать:** просто дважды кликните по нему. Оно покажет системное уведомление: *«Обновление погоды...»*, тихо обновит календарь и уведомит об успехе!
- **В Dock:** можно просто перетащить его в панель Dock и обновлять погоду в один клик мыши.
- **Автозапуск при входе в систему:** откройте **«Системные настройки» → «Основные» → «Объекты входа»** и добавьте `Обновить погоду.app` в список.

#### Как собрать такое же в самом Automator с нуля:
1. Откройте приложение **Automator** на Mac → **Новый документ** → выберите тип **«Программа»** (Application).
2. В левой панели найдите действие **«Запустить shell-скрипт»** (Run Shell Script) и перетащите вправо:
   - Shell: `/bin/zsh`
   - В поле кода вставьте:
     ```bash
     /usr/bin/python3 "/Volumes/Work SSD/works/WeatherCal/update_weather.py"
     ```
3. Ниже добавьте действие **«Показать уведомление»** (Display Notification):
   - Заголовок: `WeatherCal`
   - Сообщение: `Календарь погоды успешно обновлен!`
4. Сохраните через **Файл → Сохранить...**.
